# Google Apps Script Samples

Automation solutions built using Google Apps Script to connect and automate Google Workspace tools.

## What Is Included
- Google Sheets automation and custom functions
- Gmail workflow automation
- Google Forms data processing
- Scheduled trigger based scripts
- Cross application automation connecting Sheets, Docs, Gmail, and Calendar

## Use Cases
- Automated reporting from form submissions
- Email notifications triggered by sheet data
- Data cleanup and formatting automation
- Task and deadline reminder automation
