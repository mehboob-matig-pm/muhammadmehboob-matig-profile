# Shopify E-commerce Support

Hands-on experience managing customer support for a Shopify-based e-commerce brand through Zendesk.

## What I Handled
- Order tracking and shipping updates
- Return and refund processing via Return Helper
- Wrong address and failed delivery resolution
- Order cancellation before and after fulfillment
- International shipping inquiries
- Subscription and billing support
- Product complaint handling and escalation

## Tools Used
- Shopify Order Management
- Return Helper
- Zendesk
- Loox Reviews
- Trustpilot
