# LocationScan

An Electron desktop tool built for bulk URL location scanning.

## What It Does
- Accepts a list of URLs as input
- Scans each URL and retrieves location and geographic data
- Outputs results in a structured format for analysis
- Built for QA and data validation workflows

## Built With
- Electron
- Node.js
- JavaScript

## Use Case
Designed to streamline location-based URL verification at scale, saving hours of manual checking across large URL datasets.
